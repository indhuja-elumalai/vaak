# Vaak

A voice-first study helper that decides, per question, whether to call a deterministic tool
(calculate, convert units, look up a formula) or answer directly, and checks the numbers in
its answers against the tool results.

Source code, evaluation results and docs: https://github.com/indhuja-elumalai/vaak
